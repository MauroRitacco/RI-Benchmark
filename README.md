# RI-Benchmark

RI-Benchmark is a benchmarking framework for radio-interferometric image reconstruction. It was developed to compare CLEAN through CASA `tclean`, WSClean, FISTA with a wavelet prior through DeepInverse, and R2Disk2 on protoplanetary-disk measurements, including synthetic data with known ground truth and archival ALMA observations. Its common evaluation workflow can be adapted to other radio-interferometric datasets supplied in the supported formats.

## Overview

This repository implements the evaluation stage of a thesis research project. It provides:

- a common benchmark workflow for the four reconstruction methods;
- systematic hyperparameter sweeps on a validation dataset;
- final evaluation on a held-out test dataset excluded from hyperparameter selection;
- PSNR, SSIM, MSE, and per-image runtime measurements;
- variable-noise and archival-data studies.

R2Disk2 is the learned reconstruction method evaluated in this work. The network was trained outside this repository; RI-Benchmark performs inference using a published checkpoint. Synthetic images and measurements are generated by the companion [DiskGenerator](https://github.com/MauroRitacco/DiskGenerator).

```text
│   ├── generate_weights.sh              # Briggs imaging weights

│   └── *_targets.txt, *_config.txt      # target lists and configurations
├── src/
│   ├── algorithms/                      # CASA and DeepInverse wrappers

│   ├── archival_recon.py                # archival-data workflow

```

Data, reconstruction outputs, metric tables, virtual environments, and checkpoints are generated or stored locally and are not included in the repository. The single example target under `data/` is the exception.

## Workflow

For each synthetic target, the benchmark runs the four methods on the same input measurements and evaluates the reconstructions against the same ground truth.

```text
Target data
  → CASA tclean
  → WSClean
  → DeepInverse: FISTA + wavelet prior
  → R2Disk2 inference
  → common evaluation: PSNR, SSIM, MSE, and runtime
```

The main workflows are:

- **Single-target evaluation:** reconstruct one target with all methods and optionally compute its metrics.
- **Sweep:** evaluate the configured hyperparameter grid on the validation dataset.
- **Test:** run the selected configuration of each method on the held-out test dataset.
- **Variable-noise study:** regenerate visibility noise at three signal-to-noise levels while keeping the ground truth fixed.
- **Archival study:** reconstruct calibrated ALMA Measurement Sets without ground truth.

CASA and WSClean operate on Measurement Sets. DeepInverse and R2Disk2 consume the corresponding MAT representation. Archival Measurement Sets are converted with `src/utils/ms2mat.py` before reconstruction.

## Requirements

Each method uses its own Python 3.10 environment, with dependencies listed under `requirements/`. WSClean must also be available as a system executable. The reported DeepInverse and R2Disk2 runs used GPU environments.

The reported results used WSClean 3.7. A clean installation followed by an end-to-end run has not been re-verified for this release.

The R2Disk2 checkpoint can be downloaded with the Hugging Face CLI:

```text
hf download MauroRitacco/R2Disk2 --include "ckpt/*" --local-dir external/R2D2-RI
```

## Data

Full datasets are not distributed with the repository. One example target is included at `data/simulated/disk_s4_r2_c0_x0_005/`, allowing the pipeline to be exercised without generating data first. Its `disk_s4_r2_c0_x0_005.yaml` contains the imaging configurations selected in the final evaluation.

The expected target layout is:

```text
data/<group>/<target>/
├── <target>.MS        # Measurement Set
├── <target>.mat       # visibility representation
├── <target>.fits      # ground truth for simulated targets
├── <target>_res.fits  # dirty image or initial residual
├── <target>.json      # target metadata
└── <target>.yaml      # optional imaging-parameter overrides
```

Here, `<group>` identifies the dataset, such as `simulated` or `archival`. Archival targets do not include ground truth. A target may include an optional `<target>.yaml` file with imaging-parameter overrides; otherwise, the runners use their configured defaults.

Data sources:

- **Simulated datasets:** generated with [DiskGenerator](https://github.com/MauroRitacco/DiskGenerator).
- **Variable-noise datasets:** generated from existing simulated measurements using `src/utils/studies/noisevar/`.
- **Archival datasets:** calibrated ALMA continuum observations of HD163296, Sz114, and Sz129 from [DSHARP](https://almascience.eso.org/almadata/lp/DSHARP/).

## Usage

Run the commands from the repository root.

```text
# Run all four methods on one target, optionally computing metrics
./scripts/run_all.sh --target <target> [--compute_metrics]

# Run the same command on the included example target
./scripts/run_all.sh --target disk_s4_r2_c0_x0_005 --compute_metrics

# Hyperparameter sweep and evaluation
./scripts/run_sweep.sh [--cpu-workers N --gpu-workers M]
./scripts/run_sweep.sh --evaluate

# Held-out test with the selected configuration of each method
./scripts/run_sweep.sh --test

# Archival reconstruction, with the benchmark environment activated
python src/archival_recon.py --target <target> --casa --png

# Measurement Set to MAT conversion
python src/utils/ms2mat.py --msfile=<ms> --srcname=<name> --srcid=0 --freqid=0
```

The flags `--wsclean`, `--deepinv`, and `--r2d2` select the other archival reconstruction methods. See `src/utils/ms2matREADME.md` for MAT-format details and channel options.

## Results and reproducibility

The final evaluation used 360 held-out synthetic disks and one configuration per method, selected on the separate 360-disk validation dataset. The held-out test disks were not used for hyperparameter selection. The evaluation completed 1,440 jobs with no failures.

The sweep and held-out test datasets represent a low-noise regime. Their SNR approximately matches the R2Disk2 training regime, with values between `10^4` and `10^5`. The following table therefore describes performance in that regime; the variable-noise study evaluates performance at other SNR levels.

PSNR and SSIM are higher-is-better (↑); MSE and runtime are lower-is-better (↓). Reconstructions are evaluated in Jy/pixel, so MSE is expressed in `(Jy/pixel)²`. Runtime is the mean imaging time per target.

| Method | Configuration | PSNR (dB) ↑ | SSIM ↑ | MSE ↓ | Time/image (s) ↓ |
| --- | --- | ---: | ---: | ---: | ---: |
| DeepInverse (FISTA + wavelet) | `l0p1_i50_v2` | 46.72 | 0.9876 | 0.0003 | 15.17 |
| R2Disk2 | `k5` | 37.72 | 0.9494 | 0.0012 | 1.48 |
| CASA (`tclean` / CLEAN) | `g0p1_ts1p0` | 29.77 | 0.8192 | 0.0028 | 3.77 |
| WSClean | `g0p1_ts1p0` | 29.26 | 0.8034 | 0.0033 | 1.30 |

The table reproduces the final evaluation report dated 2026-10-08. It documents the reported benchmark, not a new verification performed for this release.

### Variable-noise study

The same 360 validation disks were re-measured with regenerated visibility
noise at three noise levels, defined by the peak SNR of the dirty image
(SNR = 50, 200 and 500), keeping the ground truth fixed (1,080 cells in
total; n = 360 per cell). Values are mean ± std over the cells of each
level; "Global" is the mean over all cells. Sweep configuration ids are
given in parentheses.

PSNR (dB), higher is better:

| Method | Configuration | SNR = 50 | SNR = 200 | SNR = 500 | Global |
| --- | --- | ---: | ---: | ---: | ---: |
| CASA (`tclean`) | 3σ_auto (`g0p1_ts3`) | 26.86 ± 4.11 | 28.51 ± 5.32 | 28.68 ± 5.48 | 28.01 |
| CASA (`tclean`) | 3σ_abs (`g0p1_a3s`) | 27.25 ± 4.23 | 29.79 ± 6.22 | 30.22 ± 6.74 | 29.08 |
| WSClean | 3σ_auto (`g0p1_ts3`) | 26.82 ± 4.47 | 28.20 ± 5.64 | 28.34 ± 5.79 | 27.79 |
| WSClean | 3σ_abs (`g0p1_a3s`) | **27.27 ± 4.63** | 29.30 ± 6.46 | 29.61 ± 6.86 | 28.72 |
| DeepInverse (BPSA) | λ = 1 (`l1_i50_v2`) | 24.21 ± 4.49 | **34.56 ± 5.20** | **40.12 ± 7.93** | **32.96** |
| DeepInverse (BPSA) | λ = 0.1 (`l0p1_i50_v2`) | 22.89 ± 4.60 | 31.39 ± 4.74 | 37.27 ± 5.89 | 30.52 |
| R2Disk2 | checkpoint `R2D2_small_ALMA3` (`k5`) | 22.87 ± 5.98 | 32.90 ± 5.98 | 36.22 ± 7.38 | 30.66 |

Mean imaging time per image (s), lower is better:

| Method | Configuration | SNR = 50 | SNR = 200 | SNR = 500 | Global |
| --- | --- | ---: | ---: | ---: | ---: |
| CASA (`tclean`) | 3σ_auto | 3.3 | 3.5 | 3.1 | 3.3 |
| CASA (`tclean`) | 3σ_abs | 3.5 | 8.1 | 7.8 | 6.5 |
| WSClean | 3σ_auto | 1.1 | 1.2 | 1.1 | 1.2 |
| WSClean | 3σ_abs | 1.0 | 1.4 | 1.7 | 1.4 |
| DeepInverse (BPSA) | λ = 1 | 14.6 | 14.1 | 14.1 | 14.2 |
| DeepInverse (BPSA) | λ = 0.1 | 14.5 | 14.1 | 14.1 | 14.2 |
| R2Disk2 | checkpoint `R2D2_small_ALMA3` | 1.6 | 1.7 | 1.5 | 1.6 |

The ranking crosses with the noise level: at SNR = 50 the CLEAN-class
methods (CASA, WSClean) lead, while at SNR = 200 and 500 DeepInverse and
R2Disk2 clearly outperform them, with DeepInverse reaching the highest PSNR
at every level above 50. Both non-CLEAN methods degrade more strongly as
noise increases. These tables reproduce the results chapter of the thesis
project; they document the reported study, not a new verification.

## Third-party code and local modifications

- `external/R2D2-RI/` is a vendored copy of [basp-group/R2D2-RI](https://github.com/basp-group/R2D2-RI), based on upstream commit `2266925` and distributed under its original GPL-3.0 license.

## Limitations

- Reproducing the full reported results requires the complete local datasets, method-specific environments, external software, and the R2Disk2 checkpoint.
- Archival results depend on externally calibrated Measurement Sets whose calibration and provenance are outside this repository.
